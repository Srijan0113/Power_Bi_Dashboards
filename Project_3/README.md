# Data Jobs Dashboard 2.0 — Power BI

![Data Jobs Dashboard](/images/Project3_Page1.png)

## Introduction

Understanding the data job market can be challenging with thousands of job postings containing different roles, salaries, skills, and locations.

This project uses **Power BI Desktop** to analyze a dataset of **2024 data science job postings** and create an interactive dashboard for exploring job demand, required skills, and salary trends.

The dashboard is designed to help users understand:

- Which data roles are in demand
- Which skills are frequently required
- How salaries vary across job titles
- The difference between yearly and hourly salaries
- How job requirements change based on selected filters

> **Note:** This project was developed and analyzed using **Power BI Desktop**. Since I do not have a Power BI Service subscription, the dashboard is provided as a `.pbix` file and screenshots rather than a published Power BI Service link.

## Dashboard Overview

The second version of the dashboard focuses on presenting the most important job-market information on a **single page**.

![Data Jobs Dashboard v2.0](../Resources/images/Project2_Dashboard_Page1.png)

The dashboard includes key metrics such as:

- **Job Count** — Number of job postings matching the selected filters
- **Skills Per Job** — Average number of skills required per job
- **Median Yearly Salary** — Median annual salary
- **Median Hourly Salary** — Median hourly salary
- **Skill Popularity** — Frequently requested skills
- **Salary by Job Title** — Comparison of salaries across different roles

Users can apply filters to explore how these metrics change for different job titles, skills, and other available attributes.
